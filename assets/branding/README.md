# Superset Remix artwork

The app icon uses the upstream Superset pixel chevrons on a flat warm-black rounded-square tile. The outer pair is off-white and the inner pair is light lavender, distinguishing Remix while retaining the original silhouette. There are no gradients, lighting, shadows or textures. `app-icon-source.svg` is the canonical vector master with transparent outer margins; `mark-source.svg` is its monochrome luminance mask. PNG sources, `mark.svg`, light/dark marks, shared renderer metadata and the menu-bar template are generated from these two SVG files. The wordmark contains only the product name.

The user requested a flatter design closer to the original on 2026-10-17. An image-generation concept used the original Superset preset icon as its reference; the final checked-in geometry follows that concept using exact solid fills and the original pixel rhythm. Original Superset authorship and license remain intact. The earlier folded S artwork remains in Git history. Exporting icon sizes and containers uses the existing pinned build pipeline, without relying on a machine's icon cache.

Run `bun run brand:generate` from the repository root. Run `bun run brand:check` to compare all 31 outputs byte for byte. JSON formatting uses pinned Biome 2.4.2. The pinned image exporter is sharp 0.34.5 (libvips 8.17.3 in the reference Linux environment); installer and badge text use the system sans-serif font, so regenerate on the same environment for exact raster comparisons. Platform CI consumes committed assets without rerasterizing them.

Outputs include the two derived PNG sources, application SVGs embedding the vector artwork, 16/24/32/128/1024 PNG proofs, light/dark SVGs, wordmark SVGs, multi-resolution ICNS (16–1024), ICO (16–256), Dev/Canary icons, monochrome template tray PNG, and DMG TIFF background. The generator also derives the shared vector renderer mask, mirrors package metadata and embeds the unchanged original license and fork notice.

The desktop sidebar uses a decorative mark beside the single textual product name. Standalone marks expose the product name to accessibility tools. D and C badges indicate development channels; they do not change the product name. Check small icons at native size, transparency, light/dark contrast and screenshot rendering. Service, agent and integration logos belong to their respective third parties and are not fork artwork.
