# SSH 连接性能实现与对比记录

状态：实施及原生验收进行中。基础：`c6cca9926`。预览版本：1.37.5。

采用方向：一条独占 OpenSSH master、合并探测、认证能力复用、V2签名压缩归档和受控流式安装。进度显示实际阶段和耗时，首次安装与日常重连单独计时。

## 已完成的 Linux 回环分项测量

真实 OpenSSH/SFTP，6,230个文件、12,759,040展开字节（12.17 MiB），一半固定文本、一半随机字节。合成数据只用于隔离握手、小文件操作和读取进程成本；不代表真实发行包压缩率或Mac完整安装。

| 方案/阶段 | 样本数 | 中位数 | P95或最大值 |
| --- | ---: | ---: | ---: |
| 独立 SSH 控制命令 | 20 | 100.23 ms | P95 106.82 ms |
| 单 master 控制命令（含首次建连） | 20 | 18.79 ms | P95 26.43 ms |
| 逐文件SFTP，独立连接 | 3 | 2,776.86 ms | 最大2,950.25 ms |
| 逐文件SFTP，单master | 3 | 2,768.49 ms | 最大2,777.87 ms |
| gzip1归档上传，单master | 20 | 63.32 ms | P95 78.11 ms |
| gzip6归档上传，单master | 20 | 50.94 ms | P95 63.59 ms |
| 逐文件启动读取进程 | 3 | 5,813.31 ms | 最大5,860.48 ms |

单master不会显著减少批次内小文件协议操作；单归档解决了这个主要开销。以上时间不可直接相加当作首装结果，也不能宣称WAN性能。gzip1/6最终取舍以真实发行物的原生完整安装数据决定。

原始样本：[Linux微基准JSON](evidence/ssh-performance/linux-loopback.json)。复现：`BENCH_SAMPLES=20 bun packages/direct-connection/src/benchmark-ssh.mts output.json`，需要独立本机sshd测试能力。该脚本不在默认快速单测中执行。
