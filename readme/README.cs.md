# Superset Remix
</div>

Místní a SSH pracovní prostředí. Neoficiální upravená verze Superset, nezávisle spravovaná bez schválení od Superset, Inc.

Desktop otevře prostředí bez účtu. Přidejte SSH počítač a připojte se: přibalený backend s ověřeným podpisem se podle potřeby automaticky přenese a nainstaluje. První instalace může vyžadovat heslo vzdáleného správce. Úlohy po odpojení pokračují.

Náhledy macOS Apple Silicon a Intel se sestavují a ověřují zvlášť. Nevydané sestavení najdete v artefaktech GitHub Actions. Zkontrolujte přiloženou verzi, zdrojový commit a kontrolní součet. Superset SSH Preview označuje starší verze. Distribuce Linux a Windows nejsou ověřené.

Používá se nový samostatný adresář superset-remix bez automatického importu starých dat. Aktualizujte ručně ze stažení tohoto forku. Podpis Apple Developer ID ani notarizace nejsou nastavené; náhledy jsou podepsané ad hoc.

Tlačítko neoficiální upravené verze zobrazí skutečnou verzi, úplnou původní licenci a oznámení změn offline. Web, cloud, mobilní aplikaci a předplatné původního projektu tento fork neprovozuje.
