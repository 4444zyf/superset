# Superset Remix
</div>

Lokale und SSH-Arbeitsumgebungen. Eine inoffizielle, unabhängig gepflegte Änderung von Superset ohne Unterstützung durch Superset, Inc.

Der Desktop öffnet eine Arbeitsumgebung ohne Konto. SSH-Rechner hinzufügen und verbinden: Das mitgelieferte, signaturgeprüfte Backend wird bei Bedarf automatisch übertragen und installiert. Dafür kann das entfernte Administratorpasswort erforderlich sein. Aufgaben laufen nach dem Trennen weiter.

macOS-Vorschauen für Apple Silicon und Intel werden separat gebaut und geprüft. Unveröffentlichte Builds stehen als GitHub-Actions-Artefakte bereit. Version, Quell-Commit und Prüfsumme liegen bei. Superset SSH Preview bezeichnet frühere Versionen. Linux- und Windows-Pakete sind nicht validiert.

Ein neues unabhängiges Verzeichnis superset-remix wird verwendet; alte Daten werden nicht automatisch übernommen. Updates erfolgen manuell über die Downloads dieses Forks. Apple-Developer-ID-Signatur und Beglaubigung sind nicht eingerichtet; Entwicklungsvorschauen sind ad hoc signiert.

Die Schaltfläche für die inoffiziell geänderte Version öffnet die tatsächliche Version, die vollständige ursprüngliche Lizenz und Änderungshinweise offline. Website, Cloud, mobile Apps und Abonnements des ursprünglichen Projekts werden nicht von diesem Fork betrieben.
