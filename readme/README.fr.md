# Superset Remix
</div>

Postes de travail locaux et SSH. Version modifiée non officielle de Superset, maintenue indépendamment et sans approbation de Superset, Inc.

Le bureau ouvre un poste de travail sans compte. Ajoutez une machine SSH et connectez-vous : le backend signé fourni est transféré et installé automatiquement si nécessaire. Le premier lancement peut demander le mot de passe administrateur distant. Les tâches distantes continuent après la déconnexion.

Les aperçus macOS Apple Silicon et Intel sont construits et vérifiés séparément. Les builds non publiés sont disponibles dans les artefacts GitHub Actions. Vérifiez leur version, commit et somme de contrôle. Superset SSH Preview désigne les anciennes versions. Les distributions Linux et Windows ne sont pas validées.

Un nouveau répertoire indépendant superset-remix est utilisé, sans import automatique des anciennes données. Mettez à jour manuellement depuis les téléchargements de ce fork. La signature Apple Developer ID et la notarisation ne sont pas configurées ; les aperçus utilisent une signature ad hoc.

Le bouton de version modifiée non officielle ouvre les informations, la version réelle, la licence originale complète et les avis hors ligne. Le site, le cloud, le mobile et les abonnements en amont ne sont pas exploités par ce fork.
