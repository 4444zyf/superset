# Superset Remix
</div>

Lokalne środowiska pracy i SSH. Nieoficjalna zmodyfikowana wersja Superset, utrzymywana niezależnie i bez poparcia Superset, Inc.

Pulpit otwiera środowisko bez konta. Dodaj maszynę SSH i połącz się: dołączony backend o zweryfikowanym podpisie jest automatycznie przesyłany i instalowany w razie potrzeby. Pierwsza instalacja może wymagać hasła administratora zdalnego. Zadania działają po rozłączeniu.

Wersje testowe macOS Apple Silicon i Intel są budowane i sprawdzane osobno. Nieopublikowane kompilacje są w artefaktach GitHub Actions. Sprawdź dołączoną wersję, commit i sumę kontrolną. Superset SSH Preview oznacza wcześniejsze wersje. Dystrybucje Linux i Windows nie są zweryfikowane.

Nowy niezależny katalog superset-remix nie importuje automatycznie starych danych. Aktualizuj ręcznie z pobrań tego forka. Podpis Apple Developer ID i notaryzacja nie są skonfigurowane; wersje testowe mają podpis ad hoc.

Przycisk nieoficjalnej zmodyfikowanej wersji otwiera rzeczywistą wersję, pełną oryginalną licencję i informacje o zmianach offline. Witryna, chmura, aplikacja mobilna i subskrypcje projektu źródłowego nie są obsługiwane przez ten fork.
