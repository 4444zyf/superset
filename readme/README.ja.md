# Superset Remix
</div>

ローカルと SSH のワークステーション。Superset の非公式改変版であり、独立して保守され、Superset, Inc. の承認を受けていません。

デスクトップはアカウント不要のワークステーションを開きます。SSH マシンを追加して接続すると、必要に応じて同梱の署名検証済みバックエンドを自動転送・インストールします。初回はリモート管理者のパスワードが必要になる場合があります。切断後もリモートのタスクは動作します。

macOS Apple Silicon と Intel のプレビューを個別にビルド・検証します。未公開のビルドは GitHub Actions の成果物にあります。同梱のバージョン、ソースのコミット、チェックサムを確認してください。Superset SSH Preview は改名前の履歴版です。Linux と Windows の配布は未検証です。

新しい独立した superset-remix データディレクトリを使い、以前のプレビューや上流のデータを自動移行しません。このフォークのダウンロードから手動更新してください。Apple Developer ID 署名と公証は未設定で、開発プレビューはアドホック署名です。

「非公式の改変版」ボタンから、実際のバージョン、元のライセンス全文、改変通知とリンクをオフラインで確認できます。上流のサイト、クラウド、モバイル、購読サービスは本フォークの運営対象ではありません。
