# Superset Remix
</div>

Lokale en SSH-werkstations. Een onofficieel gewijzigde versie van Superset, onafhankelijk onderhouden zonder goedkeuring van Superset, Inc.

De desktop opent een werkstation zonder account. Voeg een SSH-machine toe en verbind: de meegeleverde backend met gecontroleerde handtekening wordt zo nodig automatisch overgezet en geïnstalleerd. De eerste installatie kan het beheerderswachtwoord op afstand vragen. Taken blijven na het verbreken actief.

macOS-previews voor Apple Silicon en Intel worden apart gebouwd en gecontroleerd. Niet-gepubliceerde builds staan in GitHub Actions-artefacten. Controleer versie, broncommit en checksum. Superset SSH Preview zijn oudere versies. Linux- en Windows-distributies zijn niet gevalideerd.

Een nieuwe onafhankelijke map superset-remix wordt gebruikt zonder automatische import van oude gegevens. Werk handmatig bij via de downloads van deze fork. Apple Developer ID en notarisatie zijn niet ingesteld; previews gebruiken ad-hocondertekening.

De knop voor de onofficieel gewijzigde versie opent de werkelijke versie, volledige oorspronkelijke licentie en wijzigingsmelding offline. Website, cloud, mobiele app en abonnementen van het oorspronkelijke project worden niet door deze fork beheerd.
