# Superset Remix
</div>

Postazioni locali e SSH. Versione modificata non ufficiale di Superset, mantenuta in modo indipendente senza approvazione di Superset, Inc.

Il desktop apre una postazione senza account. Aggiungi una macchina SSH e connettiti: il backend incluso, verificato tramite firma, viene trasferito e installato automaticamente se manca. Può essere richiesta la password amministrativa remota. Le attività continuano dopo la disconnessione.

Le anteprime macOS Apple Silicon e Intel vengono compilate e verificate separatamente. Le build non pubblicate sono disponibili negli artefatti GitHub Actions. Controlla versione, commit e checksum inclusi. Superset SSH Preview indica versioni precedenti. Linux e Windows non sono convalidati.

Si usa una nuova directory indipendente superset-remix senza importare automaticamente dati precedenti. Aggiorna manualmente dai download di questo fork. Firma Apple Developer ID e notarizzazione non sono configurate; le anteprime usano una firma ad hoc.

Il pulsante della versione modificata non ufficiale apre versione effettiva, licenza originale completa e avvisi di modifica anche offline. Sito, cloud, app mobile e abbonamenti del progetto originale non sono gestiti da questo fork.
