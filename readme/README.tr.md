# Superset Remix
</div>

Yerel ve SSH çalışma istasyonları. Superset’in bağımsız olarak sürdürülen, Superset, Inc. tarafından onaylanmayan resmî olmayan değiştirilmiş sürümüdür.

Masaüstü, hesap gerektirmeyen çalışma istasyonunu açar. SSH makinesi ekleyip bağlanın: imzası doğrulanan paketli arka uç gerekirse otomatik aktarılır ve kurulur. İlk kurulum uzak yönetici parolasını isteyebilir. Bağlantı kesilse de uzak görevler çalışır.

macOS Apple Silicon ve Intel önizlemeleri ayrı derlenip doğrulanır. Yayımlanmayan derlemeler GitHub Actions çıktılarında bulunur. Eklenen sürümü, kaynak commit’ini ve sağlama toplamını kontrol edin. Superset SSH Preview eski sürümleri belirtir. Linux ve Windows dağıtımları doğrulanmamıştır.

Yeni bağımsız superset-remix veri dizini kullanılır; eski veriler otomatik içe aktarılmaz. Bu fork’un indirmeleriyle elle güncelleyin. Apple Developer ID imzası ve noter onayı ayarlı değildir; önizlemeler ad hoc imzalıdır.

Resmî olmayan değiştirilmiş sürüm düğmesi gerçek sürümü, tam özgün lisansı ve değişiklik bildirimini çevrimdışı açar. Kaynak projenin sitesi, bulutu, mobil uygulaması ve abonelikleri bu fork tarafından işletilmez.
