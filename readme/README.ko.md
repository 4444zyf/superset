# Superset Remix
</div>

로컬 및 SSH 워크스테이션. Superset의 비공식 수정 버전이며 독립적으로 유지 관리되고 Superset, Inc.의 승인을 받지 않았습니다.

데스크톱은 계정 없이 워크스테이션을 엽니다. SSH 머신을 추가하고 연결하면 필요할 때 서명을 검증한 번들 백엔드를 자동 업로드 및 설치합니다. 처음 설치할 때 원격 관리자 암호가 필요할 수 있습니다. 연결을 끊어도 원격 작업은 계속 실행됩니다.

macOS Apple Silicon 및 Intel 미리 보기는 별도로 빌드하고 검증합니다. 미출시 빌드는 GitHub Actions 아티팩트에서 받을 수 있습니다. 포함된 버전, 소스 커밋 및 체크섬을 확인하세요. Superset SSH Preview는 이전 이름의 과거 버전입니다. Linux 및 Windows 배포는 검증되지 않았습니다.

새 독립 데이터 디렉터리 superset-remix를 사용하며 이전 데이터를 자동으로 가져오지 않습니다. 이 포크의 다운로드에서 수동 업데이트하세요. Apple Developer ID 서명 및 공증이 설정되지 않았으며 미리 보기는 임시 서명을 사용합니다.

비공식 수정 버전 버튼에서 실제 버전, 원본 라이선스 전문 및 수정 안내를 오프라인으로 확인할 수 있습니다. 원본 프로젝트의 사이트, 클라우드, 모바일 및 구독 서비스는 이 포크에서 운영하지 않습니다.
