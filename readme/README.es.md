# Superset Remix
</div>

Espacios de trabajo locales y SSH. Versión modificada no oficial de Superset, mantenida de forma independiente y sin respaldo de Superset, Inc.

El escritorio abre un espacio de trabajo sin cuenta. Añade una máquina SSH y conéctate: el backend incluido y verificado por firma se transfiere e instala automáticamente cuando falta. La primera instalación puede pedir la contraseña de administrador remoto. Las tareas continúan al desconectarse.

Las versiones preliminares de macOS para Apple Silicon e Intel se construyen y verifican por separado. Las compilaciones sin publicar aparecen como artefactos de GitHub Actions. Comprueba su versión, commit y suma de verificación. Superset SSH Preview corresponde a versiones anteriores. Linux y Windows no están validados.

Se usa un directorio independiente nuevo, superset-remix, sin importar automáticamente datos antiguos. Actualiza manualmente desde las descargas de este fork. No hay firma Apple Developer ID ni notarización configuradas; las versiones preliminares tienen firma ad hoc.

El botón de versión modificada no oficial muestra sin conexión la versión real, la licencia original completa y los avisos de modificación. El sitio, la nube, el móvil y las suscripciones del proyecto original no son operados por este fork.
