# Superset Remix
</div>

本機和 SSH 工作站。Superset 的非官方修改版本，由獨立維護者維護，未獲 Superset, Inc. 背書。

目前桌面端直接開啟無需帳號的工作站。新增 SSH 機器並連線，缺少後端時會自動上傳並安裝隨應用附帶、經過簽章驗證的後端。首次安裝可能需要遠端管理員密碼。中斷桌面連線後，遠端工作繼續執行。

macOS Apple Silicon 和 Intel 預覽安裝包分別建置和驗證；尚未發布的建置可在 GitHub Actions 的產物中下載。以產物內的版本、原始碼提交和校驗和為準。舊版 Superset SSH Preview 為品牌修改之前的歷史版本。Linux 和 Windows 發行包尚未驗證。

使用全新的 superset-remix 獨立資料目錄，不會自動匯入舊預覽版或上游資料。透過本儲存庫下載頁手動更新。尚未設定 Apple Developer ID 簽章和公證；目前為臨時簽章的開發預覽。

介面的「非官方修改版本」按鈕開啟關於視窗，可離線查看實際版本、完整原始授權、修改說明及上游與分支連結。上游網站、雲端服務、行動版和訂閱不由此分支營運。
