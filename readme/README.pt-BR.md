# Superset Remix
</div>

Estações de trabalho locais e SSH. Versão modificada não oficial do Superset, mantida de forma independente e sem endosso da Superset, Inc.

O aplicativo abre uma estação sem conta. Adicione uma máquina SSH e conecte: o backend incluído, verificado por assinatura, é transferido e instalado automaticamente quando necessário. A instalação inicial pode exigir a senha de administrador remoto. As tarefas continuam após desconectar.

As prévias macOS Apple Silicon e Intel são compiladas e verificadas separadamente. Compilações não publicadas ficam nos artefatos do GitHub Actions. Confira versão, commit e checksum incluídos. Superset SSH Preview identifica versões anteriores. Linux e Windows não foram validados.

Usa um novo diretório independente superset-remix sem importar dados antigos automaticamente. Atualize manualmente pelos downloads deste fork. Assinatura Apple Developer ID e notarização não estão configuradas; as prévias usam assinatura ad hoc.

O botão de versão modificada não oficial mostra a versão real, a licença original completa e os avisos de modificação offline. Site, nuvem, aplicativo móvel e assinaturas do projeto original não são operados por este fork.
