# Superset Remix
</div>

Локальные рабочие среды и SSH. Неофициальная изменённая версия Superset, поддерживаемая независимо и не одобренная Superset, Inc.

Приложение открывает рабочую среду без учётной записи. Добавьте SSH-машину и подключитесь: встроенный backend с проверенной подписью автоматически загружается и устанавливается при необходимости. Может потребоваться пароль удалённого администратора. Задачи продолжают работать после отключения.

Предварительные сборки macOS для Apple Silicon и Intel создаются и проверяются отдельно. Неопубликованные сборки доступны в артефактах GitHub Actions. Проверяйте версию, коммит и контрольную сумму. Superset SSH Preview — прежние версии. Дистрибутивы Linux и Windows не проверены.

Используется новый независимый каталог superset-remix без автоматического импорта старых данных. Обновляйте вручную из загрузок этого форка. Подпись Apple Developer ID и нотарификация не настроены; сборки используют подпись ad hoc.

Кнопка неофициальной изменённой версии открывает фактическую версию, полный текст исходной лицензии и уведомления об изменениях без сети. Сайт, облако, мобильные приложения и подписки исходного проекта не управляются этим форком.
