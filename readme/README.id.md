# Superset Remix
</div>

Stasiun kerja lokal dan SSH. Versi modifikasi tidak resmi dari Superset, dikelola secara independen tanpa dukungan resmi Superset, Inc.

Desktop membuka stasiun kerja tanpa akun. Tambahkan mesin SSH dan hubungkan: backend bawaan dengan tanda tangan terverifikasi diunggah dan dipasang otomatis bila belum tersedia. Pemasangan awal mungkin meminta sandi administrator jarak jauh. Tugas tetap berjalan setelah terputus.

Pratinjau macOS Apple Silicon dan Intel dibangun dan diperiksa terpisah. Build yang belum diterbitkan tersedia dalam artefak GitHub Actions. Periksa versi, commit sumber, dan checksum yang disertakan. Superset SSH Preview adalah versi lama. Distribusi Linux dan Windows belum divalidasi.

Direktori data independen baru superset-remix digunakan tanpa mengimpor data lama secara otomatis. Perbarui secara manual dari unduhan fork ini. Tanda tangan Apple Developer ID dan notarisasi belum dikonfigurasi; pratinjau menggunakan tanda tangan ad hoc.

Tombol versi modifikasi tidak resmi membuka versi sebenarnya, lisensi asli lengkap, dan pemberitahuan perubahan secara offline. Situs, layanan cloud, aplikasi seluler, dan langganan proyek asal tidak dioperasikan oleh fork ini.
